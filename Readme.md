# Python CSV Cleaner

## Project Description
A Python automation project that cleans CSV files using the Pandas library.

## Features
- Read CSV files
- Remove duplicate records
- Remove completely empty rows
- Clean extra spaces
- Generate a cleaned CSV output file

## Technologies Used
- Python
- Pandas
- CSV

## Project Structure
- cleaner.py - Main Python program
- input.csv - Original data
- cleaned_output.csv - Cleaned data
- README.md - Project documentation

## How to Run

Install Pandas:

pip install pandas

Run the program:

python cleaner.py

## Output
The program generates cleaned_output.csv automatically.
